🗺️ Lộ Trình Triển Khai 8 Tuần (Kế hoạch đồ án)
Đang ở: Tuần 1
  • Tuần 1 (Hiện tại): Khởi tạo dự án, phân tích chức năng/vai trò/luồng, khung giao diện Frontend, Backend Express có /api/health.
  • Tuần 2: Thiết kế CSDL MySQL, database.sql, kết nối CSDL và xây dựng API CRUD người nhận/nhóm người nhận.
  • Tuần 3: Xác thực đăng nhập, phân quyền, API quản lý chiến dịch và tạo danh sách thông báo chờ gửi.
  • Tuần 4: Cài đặt RabbitMQ trên Windows, cấu hình AMQP, queue bền vững và Producer đẩy tác vụ.
  • Tuần 5: Xây dựng Worker độc lập, chạy ít nhất 3 Worker xử lý song song, ACK/NACK, retry và ghi nhận trạng thái.
  • Tuần 6: Tích hợp Nodemailer/SMTP gửi email, chế độ test an toàn, kết nối toàn diện Frontend với API.
  • Tuần 7: Dashboard thống kê, lịch sử gửi, bộ lọc, kiểm thử các tình huống sự cố (Worker crash, SMTP lỗi, RabbitMQ reconnect).
  • Tuần 8: Rà soát mã nguồn, hoàn thiện tài liệu, sơ đồ kiến trúc, kịch bản demo và bảo vệ đồ án.
