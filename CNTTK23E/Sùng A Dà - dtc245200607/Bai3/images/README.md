# Ảnh Bài 3

Các PNG trình bày lại log và phản hồi HTTP từ lần build/chạy API và client thực tế, để dễ đọc và nộp theo tên bước ở bài giảng. Bộ ảnh gồm `buoc1-build.png`, `buoc2-negotiate.png`, `buoc4-echo.png`, `buoc5-nhom.png`, `buoc6-noilai.png`, `buoc7-loi1.png`–`buoc7-loi3.png`, `edusubmit-requests.png` và `edusubmit-graded.png`.

Các SVG là hình giải thích khái niệm: `mep-transports.svg` (Polling/Push/Streaming), `pinghub-methods.svg` (Hub và nhóm), `reconnect-lifecycle.svg` (vòng đời kết nối), và `edusubmit-flow.svg` (quy trình REST + SignalR).
